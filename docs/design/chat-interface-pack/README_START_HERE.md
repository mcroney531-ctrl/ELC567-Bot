# AI Workflow Builder — Chat Interface Implementation Pack

Start here.

This package is the implementation handoff for the **AI Workflow Coach chat interface** inside the AI Workflow Builder learning experience.

The chat screen must feel like the same product as the locked home timeline and learning-stage shell, but it has a different functional job: sustained conversation, coaching, and structured in-chat guidance.
