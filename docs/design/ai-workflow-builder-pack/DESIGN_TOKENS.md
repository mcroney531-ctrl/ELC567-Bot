# Design Tokens / Working Visual System

These are implementation-oriented working tokens derived from the approved direction. Preserve the relationships even if exact values are tuned during integration.

## Foundation

- Background deep charcoal/slate: `#0B1C2A`
- Background raised slate: `#132A3D`
- Frosted surface: `rgba(34, 58, 86, 0.88)`
- Glacier structural line: `#DFF2FF`
- Glacier glow: `rgba(185, 225, 255, 0.55)`
- Primary text: `#F7FAFF`
- Secondary text: `#B9CBE0`

## State cues

- Available green: `#3AF0AB`
- Current green: `#2CFF8C`
- Current glow: `rgba(44, 255, 140, 0.42)`
- Locked neutral: `#8EA4BF`

## Stage identity

- Identify blue: `#4AA2FF`
- Map aqua/teal: `#53DFD7`
- Envision amber/orange: `#FFB23D`
- Refine violet: `#CA62FF`
- Deploy cyan: `#63D7FF`

## Completed marker accents

Use darker/richer variants of the stage identity:

- Identify complete: `#166CC8`
- Map complete: `#118F88`
- Envision complete: `#B86B08`
- Refine complete: `#7E38B6`
- Deploy complete: `#278AAE`

## Radius / depth

- Major card radius: 22–28px
- Small tile radius: 16–22px
- Waypoints: circular
- Border: 1–2px
- Frosted surface should feel translucent, not opaque
- Use subtle inner highlights and restrained outer bloom

## Typography

- Eyebrow: uppercase, tracked out, smaller
- Main heading: large, bold, high-contrast
- Stage title: bold
- Stage descriptor: lighter, smaller, secondary contrast
- Keep copy compact to preserve card breathing room

## Timeline

- one continuous glacier line
- no rainbow segmented connector
- local state color belongs to nodes/cards, not to the line
