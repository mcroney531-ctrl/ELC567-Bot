# Asset Manifest

All assets in `/assets` were generated as standalone reference assets. They are not crops taken from the full progression board.

## 01_full_page_template.png
Purpose: overall layout scaffold. Use for card positions, alternating composition, timeline relationship, header placement, lower state-progression zone, and ambient tech patterning.

## 02_card_locked_identify.png
Purpose: locked card treatment reference: muted interior, reduced saturation, lock cue, low-energy border/glow, subdued copy/icon.

## 03_card_available_map.png
Purpose: available treatment reference: calm green readiness cue, native identity visible, static glow, ready/clickable without pulse.

## 04_card_current_envision.png
Purpose: current-state reference: stronger green active layer, greater glow/elevation, stage identity still visible. Current is distinguished by intensity/motion.

## 05_card_completed_refine.png
Purpose: completed-state visual reference. If any small detail conflicts with the state spec, the state spec wins. Canonical completed behavior is locked-like interior + native-color outer stroke + dimmed original icon/text + large circled check overlay + matching stage-color completed timeline star.

## 06_waypoint_locked.png
Purpose: neutral silver/glacier waypoint.

## 07_waypoint_available.png
Purpose: calm green available node.

## 08_waypoint_current.png
Purpose: brighter green current node with pulse/intensity.

## 09_waypoint_completed_star.png
Purpose: completed star-in-circle treatment. Production uses stage-specific color variants.

## 10_step_state_progression_strip.png
Purpose: bottom explainer strip reference. Production should use the same real state components/tokens as the journey map whenever practical.
