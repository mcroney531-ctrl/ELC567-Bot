# Learning Stage Behavior Spec

## Locked state definitions

### Page shell
- constant dark shell
- constant light workspace
- no stage-wide recoloring

### Top mini-node strip
- state-bearing system
- primary place where progression is expressed

### Left contextual panel
- stage identity + illustration
- does not express the full progression state system on its own

### Right workspace
- content-first instructional area
- mostly neutral

## Top mini-node state logic

### Locked
- glacier/silver neutral styling
- dimmed icon
- inactive

### Available
- calm green active-ready styling
- no pulse
- enterable

### Current
- brighter green styling
- subtle pulse
- in progress

### Completed
- stage-colored completed star treatment
- same exact family as home timeline completed stars
- not converted to generic blue checks
- should still feel clearly finished, not active

## Stage identity color mapping

- 01 Identify = blue
- 02 Map = aqua/teal
- 03 Envision = orange/amber
- 04 Refine = purple/violet
- 05 Deploy = cyan/cool teal

Completed top icons use the native stage color family for the star treatment.
